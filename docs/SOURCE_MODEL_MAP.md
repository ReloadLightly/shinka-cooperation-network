# Empirical source and executable mechanism map

The independent extension baseline is the **predictive Model 3** assembled in `scripts/00.gof.predict`, not the main paper's Model 4. The bridge is `R/empirical.R`; `R/source_parity.R` independently executes the untouched source data builder and predictive specification prefix and compares actual matrices, composition, effect identities, internal parameters, and initial values. Its result is written to `results/audits/source_parity.json` when executed.

| Ordinal defense effort | `milexPerGDP_1`, cuts `[0,.01),…,[.09,.10),[.10,1)` labelled 1–11; right boundary excluded | Exact fixed bins, RMSE stays in category units |

The original spatial lag row-normalizes each year's contiguity matrix, uses zero for countries with no contiguous neighbors, substitutes zero for missing *continuous* spending when computing that lag, and multiplies the two. It does not recompute the lag from ordinal categories. The empirical builder excludes countries whose behavior is missing throughout the chosen training span, then retains composition intervals from each country's first through last observed wave. It does not globally remove every country with any missing value. Distance is constant using the final training covariate wave; the other monadic/dyadic predictors vary over training intervals. The bridge keeps these details and verifies them against the shipped source.

## Interpretation of the finite candidate catalog

The catalog uses genuine symmetric-network effects present in RSiena 1.3.10's `data/allEffects.csv`. `degPlus` is degree activity plus popularity (internal parameter 1); `transTriads` counts transitive closure; `inPop` is degree of alter; and `gwesp` is geometrically weighted edgewise shared partners with the native fixed internal parameter 69. Maximum three optional structural effects are allowed. Statistical identification remains an empirical requirement: availability in the package does not imply that a combination is estimable. No candidate-defined utility or coefficient tuning is injected into RSiena.

## Original prediction protocol discrepancies

`02.appendix.R` sets training years to 1990–2008, whereas the appendix text describes 1990–2009. `00.gof.predict` subsequently rebuilds observations for 2009–2010. It saves validation-derived initialization rates before importing fitted training coefficients, then restores network and behavior rates from those validation starts. The same script retains both directions when flattening symmetric simulated/observed SAOM networks, but explicitly uses `ccode1 < ccode2` for its logit comparator. `paper_reproduction` must preserve those original choices. The extension below must not inherit them.

## Training-only forward construction and centering

`R/forecast.R` reads only `data/past/<target>.rds`. Its separate scorer opens target packets after the prediction file is atomically written. Unknown origin entries use last observed history (network fallback zero, behavior fallback training modal category, covariates fallback training mean). Origin membership is carried forward without target composition information. All model countries remain represented; actors absent at origin are inactive during the forecast. Scoring excludes origin-missing or origin-inactive pairs under the common eligibility rule.

The two-wave forward object has a duplicate-origin network placeholder. Its behavior placeholder starts as the origin and sets two entries to the training support boundaries. These are explicitly scaffolding values, never fabricated observations or target outcomes. They prevent native C++ from inadvertently narrowing the behavior support to the values present only at the origin. `allowOnly=FALSE` for both processes disables automatic creation-only/dissolution-only/no-change flags. `cond=FALSE`, `simOnly=TRUE`, `nsub=0`, all included effects fixed, and trained rates override all endpoint-derived initialization. The annual interval carries the final finite training-interval rate separately for each process with duration multiplier one.

RSiena's native `BehaviorLongitudinalData::calculateProperties()` computes behavior mean and support directly from both supplied waves. Overwriting R attributes would not freeze these quantities. Monadic and dyadic covariates are explicitly centered at their training means before entering the forward object with `centered=FALSE`. Behavior centering is preserved by exact reparameterization: with `d = mu_forward - mu_training`, set network density to `beta_density + beta_alt_spending*d` and behavior linear shape to `beta_linear + 2*beta_quadratic*d`. Native `CovariateAlterEffect` uses the centered alter value; `QuadraticShapeEffect` uses the centered square. These transformations preserve all microstep objective differences, rather than refitting or tuning coefficients. Their values, both means, carried rates, behavior support and disabled monotonic flags are written into forecast audits.

## Estimation acceptance

RSiena 1.3.10 `man/siena07.Rd` says absolute convergence t-ratios should be below 0.1 and overall maximum convergence below 0.25. The bridge applies both strict inequalities, additionally requiring finite estimates and positive finite standard errors. The fixed policy allows three attempts, carrying the previous fit through `prevAns`; each full attempt and diagnostics are archived. The predictive settings are `nsub=3,n3=1000`, matching the authors' validation fit, rather than their main-estimation `nsub=5,n3=3000`. Estimation failures do not receive scientific fitness.

## Mathematical objective and native change statistics

Writing symmetric ties as `x_ij`, degree as `d_i`, centered ordinal effort as `z_i`, and the preserved empirical controls as `q`, the network objective is the linear RSiena statistic model `f_i^X(x,z,q) = beta_density*d_i + beta_degree*s_degree_i(x) + beta_closure*s_closure_i(x) + sum_k beta_k*s_control_ki(x,z,q)`. The original Model 3 uses both degree activity/popularity and transitive-triad statistics. `BothDegreesEffect::tieStatistic` adds the ego and alter degrees for each adjacent alter (its parameter 1 uses degrees, not square roots). `TransitiveTripletsEffect::tieStatistic` uses the number of two-paths to each adjacent alter. On an undirected graph, the latter sums ordered closed two-paths and therefore counts each ego-centered triangle twice; do not silently substitute an unscaled triangle count. Rates govern opportunity timing, and type 3 governs initiative with reciprocal confirmation.

The fixed spending objective has linear/quadratic `z_i` terms, exogenous-control interactions with `z_i`, the degree interaction, and `z_i` times the dense-triad count from `DenseTriadsBehaviorEffect` with parameter 6. Its native change statistic for a spending change `h` is `h*denseTriadCount(i)`. Model 4 additionally interacts dense triads with total alter effort, but that is absent from the predictive baseline. These country objective functions are distinct from `evaluate.py`'s independently fixed mean improvement in held-out PRROC integral.

A deeper native-source audit corrected the initial forecast composition implementation **before any valid candidate comparison**. The earlier statement that `c(1,1)` causes a departure at time zero was incomplete: `unpackCompositionChange` discards events whose times are at or below `1e-10`. That representation therefore leaves the actor initially active. Moreover, the ordinary proposal code in `NetworkVariable.cpp` comments out its receiver-activity check for Siena3 compatibility. A diagnostic with explicitly false activity flags still produced a tie to inactive country 260; the behavior process correctly remained unchanged. Those failed diagnostics and native traces are retained in `logs/forward_composition_v2_native.log` and `logs/forward_composition_native_trace2.log`.

The corrected forward adapter holds the original country universe, sets native activity flags to origin membership at both scaffold waves, has no composition events, and supplies genuine RSiena structural-zero code 10 for dyads incident to origin-inactive countries. Only those known-invalid dyads are constrained; all eligible active-country dyads retain ordinary binary values and unrestricted formation/dissolution. Native preprocessing converts structural-zero data to zero-valued ties plus a no-change structural flag. Endpoint assertions require zero ties for inactive actors and unchanged inactive behavior. This is a pinned-version native data adapter, not a replacement simulator or a modification of the installed RSiena engine.

Forecast schema `training-only-v2-fixed-origin-membership` prevents the scorer from accepting older prediction files. Completed training fits are unaffected by this forward-only correction and may be transferred only with explicit unchanged training-identity provenance; old forecast artifacts must be quarantined. The unmodified paper reproduction continues to use the authors' original composition handling.

The illustrative ABM explicitly changes `degPlus` to internal parameter **2**, which uses square-root degrees. The empirical predictive specification leaves its native internal parameter at **1**, which uses untransformed degrees. The adapter asserts parameter 1 for empirical candidates. Treating these as interchangeable would change the baseline model.

The extension uses one native RSiena process (`useCluster=FALSE`) for both baseline and candidates because the available memory does not support concurrent empirical fits. This preserves model dynamics and inference settings but changes the random-number execution path relative to the authors' two-worker predictive call. Its fixed fitting seeds are `12345 + attempt - 1`; its forecast seeds are `target*1000+1`. This computational departure applies only to `evolution_forecast`, and is included in the adapter hash used for caching. The paper reproduction harness retains the original worker setting.

Before the first accepted empirical fit, the acceptance policy was made explicit about native execution status. A fit must have `OK=TRUE`, termination `"OK"`, a complete 1,000-iteration phase 3, a finite entire coefficient covariance matrix, no native divergence/fixing flags, and no covariance-error message. All included terms in this adapter are statistically estimated; unexpected native parameter fixing therefore changes the requested specification and is invalid. The native `newfixed` field may be absent; absence is recorded without inventing parameter-level flags. Interrupted or partial fits cannot pass merely because some coefficients and standard errors remain finite. Covariance eigenvalues and condition number are reported, but no arbitrary absolute eigenvalue cutoff is imposed on differently scaled coefficients. RSiena's own `phase3.r` already detects nonpositive statistic covariance and marks affected coefficient covariance entries missing. The original strict t-ratio/convergence thresholds remain unchanged.
